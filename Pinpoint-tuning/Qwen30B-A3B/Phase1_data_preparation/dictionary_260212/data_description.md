## Path Patchingデータ

### 生成フロー

  igakuQA (11,584件)
    → アノテーション（medical_terms_dictionary使用）
    → annotated_medical_data_full.jsonl (9,374件)
    → counterfactual生成（replacement_mapping使用）
    → counterfactual_overlap_medical/reasoning.jsonl (各5,003件)
    → path_patching_data_overlap_medical/reasoning.jsonl (各5,003件)

### 2x2マトリックス（annotated_medical_data_full.jsonl 9,374件）

  医療用語 = replacement_mappingに載っている用語が1語以上含まれる
  推論キーワード = reasoning_keywords カテゴリの用語が1語以上含まれる

  ┌────────────────┬──────────────────────┬──────────────────────┐
  │                │ 推論キーワード: なし │ 推論キーワード: あり │
  ├────────────────┼──────────────────────┼──────────────────────┤
  │ 医療用語: なし │     1,245 (対象外)   │      1,866 (対象外)  │
  ├────────────────┼──────────────────────┼──────────────────────┤
  │ 医療用語: あり │     1,260 (対象外)   │      5,003 ← overlap │
  └────────────────┴──────────────────────┴──────────────────────┘

  ポイント:
  - 5,003件: 医療用語も推論キーワードも両方置換可能 → path patchingに使用
  - 1,260件: 医療用語のみ置換可能（推論キーワードなし）
  - 1,866件: 推論キーワードのみ置換可能（医療用語なし）
  - 1,245件: どちらも置換不可 → path patching対象外

  旧データ（Phase1_data_preparation/直下）: 4,393件
  本データ（dictionary_260212/）:           5,003件（+610件 / +13.9%）
