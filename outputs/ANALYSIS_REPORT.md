# 医療LLM Post-Training 手法比較 分析レポート

## 1. Introduction

本レポートは、医療ドメインにおけるLLMの後段学習（Post-Training）手法の有効性を比較分析する。
具体的には、以下の2系統のアプローチを検証した:

1. **RL系手法**: GRPO / GSPO / CHORD（80Bモデル上）
2. **Pinpoint SFT**: Attention Head Impact分析に基づく選択的SFT（30Bモデル上）

主要な評価軸は、医師国家試験（igakuqa）および専門医試験（specialist_exam_test_v2）での正解率である。

## 2. Experimental Setup

### 2.1 ベースモデル

| モデル | パラメータ | アーキテクチャ |
|--------|-----------|---------------|
| Qwen3-30B-A3B-Instruct-2507 | 30B (A3B MoE) | qwen3_moe |
| Qwen3-Next-80B-A3B-Instruct | 80B (A3B MoE) | qwen3_next |

### 2.2 学習手法

#### A. Pinpoint SFT（30Bモデル上）

PatchPatching法によりAttention Headの医療タスクへの影響度（medical_impact / reasoning_impact）を測定し、
特定のHeadを含むLayerのみを選択的にfine-tuneする手法。

**ヘッド選択基準:**

| 手法 | 選択基準 | 意味 |
|------|---------|------|
| Positive Pinpoint | medical_impact > 0 かつ reasoning_impact > 0 | 医学用語マスク時に正解率が上がるヘッド → 正答を妨害 → 修正対象 |
| Negative Pinpoint | medical_impact < 0 かつ reasoning_impact < 0 | 医学用語マスク時に正解率が下がるヘッド → 医療タスクと正の関連 |

**PatchPatchingのimpactスコア統計:**

| | Positive (378 heads) | Negative (457 heads) |
|---|---------|----------|
| medical_impact 平均 | +0.0061 | -0.0075 |
| reasoning_impact 平均 | +0.0067 | -0.0076 |
| 特記 | 個々のimpactが小さく集団的効果 | Layer9:Head3 medical_impact=-0.624 が突出 |

**構造的特徴:**

| | Positive | Negative |
|---|---------|----------|
| 対象Layer数 | 46/48層 | 48/48層 |
| 対象Head数 | 378/1536 (24.6%) | 457/1536 (29.8%) |
| Head集中域 | **浅い〜中間層** (L0:15, L1:16, L24:18) | **深い層** (L45:23, L47:21, L44:20) |

> Positiveヘッドは浅い層に集中し、Negativeヘッドは深い層に集中する。
> これは浅い層が医学知識の「干渉」、深い層が「推論」を担うことを示唆する。

**共通学習設定:**

- lr=1e-4, max_epochs=1, global_batch_size=32, max_length=4096
- Freeze: router, shared_expert, embed_lm_head
- Unfreeze: MLP, attention（指定head以外も同一layerなら学習対象）
- データ: `sft_igakuqa_v2.jsonl`

#### B. RL系手法（80Bモデル上）

| 手法 | 特徴 | beta | chinese weight | steps_per_gen | 備考 |
|------|------|------|---------------|--------------|------|
| GRPO | 標準GRPO | 0.1 | 1.0 | 5 | - |
| GSPO | Importance Sampling付き | 0.1 | **0.3** | **3** | epsilon=3e-4 |
| CHORD | GRPO+SFT hybrid | 0.1 | 1.0 | 5 | SFTデータ併用, mu_peak=0.1 |

- 共通: lr=1e-6, max_epochs=5, global_batch_size=512, num_generations=16
- 報酬関数: `ophtho`(汎用正解判定, weight=1.5) + `chinese`(中国語ペナルティ)
- RLデータ: `igakuqa.jsonl`（GRPO形式, MCQ選択式）
- CHORDのSFTデータ: `chord_igakuqa.jsonl` — `generate_chord.py` による2ステップ合成パイプラインで生成（MCQ→自然質問→構造化医療回答）。GRPO用データ（MCQ選択式）と**完全に異なるフォーマット**

> **交絡因子**: GSPO は chinese weight と steps_per_gen が他手法と異なる。
> CHORDはSFTデータのフォーマットがRL用データ/評価タスクと大きく乖離している。
> 純粋な手法効果の分離は困難。

### 2.3 評価データセット

| データセット | 内容 | 全問題数 | テキストのみ(subset) |
|-------------|------|---------|---------------------|
| igakuqa | 医師国家試験 (2023-2025) | 1,122問 | 807問 |
| specialist_exam_test_v2 | 専門医試験 (13診療科) | 3,757問 | 2,793問 |
| guideline_wrong_filtered | 診療ガイドライン | 5,178問 | N/A |

### 2.4 評価指標

- **accuracy**: 全問題での正解率
- **subset_accuracy**: テキストのみ問題（画像参照なし）の正解率 → LLMの公正な評価指標
- **統計検定**: McNemar検定（paired comparison）, Bootstrap 95% CI (2000回)
- **データリーク**: なし（学習データは2022年以前の過去問、評価は2023-2025年）

## 4. Discussion

### 4.1 RL系手法の安定した改善メカニズム

RL系手法が安定した改善を達成した要因:

1. **低学習率（lr=1e-6）**: 既存の知識を保持しつつ微調整
2. **KLペナルティ（beta=0.1）**: ベースモデルからの逸脱を制約
3. **報酬信号による学習**: 正解/不正解の直接的なフィードバック
4. **大規模生成数（num_generations=16）**: 多様な応答パターンの探索

specialistでの有意な改善（+2.1pt, p=0.0013）は、igakuqa（医師国試）データで学習しながらも
**汎化能力を維持・向上**させたことを示す。

GRPO/GSPO間に有意差がないことは、importance samplingの追加効果が限定的であることを示唆。
ただし、GSPOのchinese weight（0.3 vs 1.0）とsteps_per_gen（3 vs 5）が異なるため、
純粋な手法効果の比較には追加実験が必要。

CHORDがspecialistで有意差に達しなかった（p=0.119）理由として、SFTデータのフォーマット問題が大きい。
CHORDのSFTデータ（`chord_igakuqa.jsonl`）は自然言語QA形式（要点/原因/対応/受診目安の構造化回答）で、
評価タスク（MCQ + `[ans]...[/ans]`）と大きく乖離している。この不整合がRL部分の改善を相殺した可能性がある。
SFTデータをGRPO用と同一のMCQ形式に揃えれば、CHORDの性能がGRPO/GSPO並かそれ以上に改善する可能性がある。

### 4.2 Pinpoint SFTの劣化原因

Pinpoint SFTが大幅劣化した主要因を以下の順序で考察:

**1. 学習率が高すぎる（lr=1e-4）**

RL系の100倍の学習率は、たとえ一部のヘッドのみを対象としても既存知識の破壊を招く。
特に `pinpoint_freeze_mlp=false` のため、対象Layer全体のMLPも学習対象となり、
ヘッド選択の「選択性」が大幅に薄まっている。

**2. 学習対象範囲が広い**

- 全48層中46-48層が対象
- 全1536ヘッドの25-30%が対象
- 同一Layer内のMLP/attention全体も学習

「Pinpoint（ピンポイント）」の名称に反し、実質的にはほぼfull fine-tuningに近い。

**3. KL制約の欠如**

RL系手法のbeta=0.1によるKLペナルティに相当する正則化がSFTにはなく、
ベースモデルからの無制約な逸脱を許容している。

**4. Catastrophic Forgetting**

igakuqaデータのみでのSFTにより、specialistで-16ptという大幅劣化が発生。
学習データに含まれない知識領域が優先的に破壊された。

### 4.3 Attention Head分布の示唆：浅い層 vs 深い層

PatchPatching分析から得られた構造的知見:

- **Positiveヘッド（浅い層に集中）**: 医学用語マスク時に正解率が上がる → 浅い層の汎用的特徴が医療タスクに干渉
- **Negativeヘッド（深い層に集中）**: 医学用語マスク時に正解率が下がる → 深い層がタスク固有の推論を担当

この分布パターン自体はモデル内部構造の有意義な発見であり、
「浅い層 = 汎用的な干渉」「深い層 = ドメイン固有の推論」という仮説を支持する。

ただし、今回のSFT設定ではこの知見を有効に活用できなかった。
適切なlr設定（1e-6以下）とより限定的なfreeze設定（MLPのfreeze、層数の絞り込み）により、
PatchPatchingに基づくPinpoint SFTが有効に機能する可能性は残されている。

### 4.4 診療科間の知識転移

RL系手法の改善パターンは診療科により異なる:

- **大幅改善科**: 耳鼻科(GRPO +8.6), 神経内科(GRPO +5.9), 肝臓(GSPO +5.2), 産婦人科(GSPO +4.8)
- **改善なし/劣化科**: 精神科(GRPO -1.1), 外科(GRPO -1.1)

学習データ（igakuqa）は全診療科を含む医師国試であるが、特定科への転移効果に偏りがある。
これはベースモデルの科別到達度と残余の改善余地に依存していると考えられる。

### 4.5 ガイドライン問題の困難性

guideline_wrong_filteredの正解率が全モデルで10-16%台にとどまる理由:

- ガイドライン改訂内容はLLMの学習データのカットオフ以降に更新された可能性
- 「誤り」を含む文の正誤判断は、正確な最新知識を必要とする
- 80Bでも改善しないことから、モデルサイズではなく**知識の鮮度**が律速因子

## 5. Limitations & Future Work

### Limitations

1. **30B vs 80Bの直接比較は不可**: モデルサイズ、手法、学習率が全て異なり、Pinpoint SFT vs RL の公正な比較ではない
2. **RL手法間の交絡因子**: GSPO（chinese=0.3, steps=3）とGRPO/CHORD（chinese=1.0, steps=5）の設定差、CHORDのSFTデータフォーマット（自然言語QA形式 vs MCQ選択式）の不整合
3. **Pinpoint SFTは1設定のみ**: 最適lrやfreeze設定の探索は未実施
4. **SFTのepoch数(1) vs RLのepoch数(5)**: 学習量の差も交絡因子
5. **guideline_wrong_filtered**: RL系モデルでの評価なし
6. **specialist_exam_v2（年度別）**: GRPO/CHORDのみ → 全手法での年度別比較不可

### Future Work

1. **Pinpoint SFTの設定改善**:
   - lr を 1e-6 に下げる
   - `pinpoint_freeze_mlp=true` でMLP を固定
   - 対象ヘッド数を top-k に絞る（例: impact上位50ヘッド）
   - KL正則化の追加
2. **公正な手法比較**: 同一モデル（80B）上で Pinpoint SFT と RL を同一条件で比較
3. **報酬関数の改善**: 科別の性能差を考慮した適応的な報酬設計
4. **ガイドライン問題**: RAG (Retrieval-Augmented Generation) による最新ガイドライン知識の注入
5. **RL手法の統制実験**: 同一ハイパーパラメータでのGRPO/GSPO/CHORD比較
