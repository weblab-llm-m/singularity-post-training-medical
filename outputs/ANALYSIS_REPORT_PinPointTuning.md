# PinPoint Tuning 分析レポート
## Attention Head Impact分析に基づく選択的SFT on Qwen3-30B-A3B-Instruct-2507

---

## 1. Introduction

本レポートは、PatchPatching法によるAttention Head Impact分析に基づき、
特定のLayer/Headのみを選択的にfine-tuneする「PinPoint Tuning」の有効性を検証する。

Qwen3-30B-A3B-Instruct-2507 をベースモデルとし、医学用語マスク時のimpactスコアに基づいて
2種類のヘッド選択方式（Positive / Negative）でSFTを行い、
医師国家試験（igakuqa）および専門医試験（specialist_exam_test_v2）で評価した。

---

## 2. Experimental Setup

### 2.1 ベースモデル

| モデル | パラメータ | アーキテクチャ |
|--------|-----------|---------------|
| Qwen3-30B-A3B-Instruct-2507 | 30B (A3B MoE) | qwen3_moe |

### 2.2 PatchPatching によるヘッド選択

各Attention Headについて2種類のimpactスコアを計測:
- `medical_impact`: 医学用語をマスクした際の正解率変動
- `reasoning_impact`: 推論プロセスへの影響度

両スコアが**同符号**のヘッドを選択:

| 手法 | ヘッド選択基準 | 意味 |
|------|--------------|------|
| **Positive Pinpoint** | medical_impact > 0 かつ reasoning_impact > 0 | 医学用語マスク時に正解率が**上がる**ヘッド → 正答を**妨害**している → 修正対象 |
| **Negative Pinpoint** | medical_impact < 0 かつ reasoning_impact < 0 | 医学用語マスク時に正解率が**下がる**ヘッド → 医療タスクと**正の関連**がある |

### 2.3 Impactスコア統計

| | Positive (378 heads) | Negative (457 heads) |
|---|---------|----------|
| medical_impact 範囲 | +0.0000 ~ +0.0494 | -0.6238 ~ -0.0000 |
| medical_impact 平均 | +0.0061 | -0.0075 |
| reasoning_impact 範囲 | +0.0000 ~ +0.1291 | -0.1965 ~ -0.0000 |
| reasoning_impact 平均 | +0.0067 | -0.0076 |

> Negativeヘッドの方がimpactの絶対値が大きい（特にLayer9:Head3のmedical_impact=-0.624は突出）。
> 一方Positiveヘッドは個々のimpactが小さく、多数のヘッドの蓄積で影響を及ぼしている。

データソース: `both_positive_heads.json`, `both_negative_heads.json` (pinpoint_sft/)

### 2.4 Pinpoint設定の詳細

| | Positive | Negative |
|---|---------|----------|
| 対象Layer数 | 46/48層 (Layer 43,45 除外) | 48/48層 (全層) |
| 対象Head数 | 378/1536 (24.6%) | 457/1536 (29.8%) |
| Head集中層 (Top5) | L24:18, L22:17, L1:16, L0:15, L26:14 | L45:23, L47:21, L44:20, L16:20, L43:19 |
| 浅い層(0-15)のHead | **多い** (L0:15, L1:16) | 少ない (L0:3, L1:1) |
| 深い層(38-47)のHead | 少ない (1-6 heads/layer) | **多い** (12-23 heads/layer) |
| Expert指定 | なし（コメントアウト） | なし（コメントアウト） |

**重要な構造的差異**: Positiveヘッドは浅い〜中間層に集中、Negativeヘッドは深い層に集中。
これはモデル内部で、浅い層が医学知識の「干渉」、深い層が医学タスクの「推論」を担うことを示唆する。

## 4. Discussion

### 4.1 劣化原因の分析

Pinpoint SFTが大幅劣化した主要因を優先度順に考察:

**1. 学習率が高すぎる（lr=1e-4）**

一般的なSFTの学習率としても高めであり、選択的ヘッドの学習でも既存知識の破壊を招く。
特に `pinpoint_freeze_mlp=false` のため、対象Layer全体のMLPも学習対象となり、
ヘッド選択の「選択性」が大幅に薄まっている。

**2. 学習対象範囲が広い**

| | Positive | Negative |
|---|---------|----------|
| 対象Layer | 46/48層 (95.8%) | 48/48層 (100%) |
| 対象Head | 378/1536 (24.6%) | 457/1536 (29.8%) |
| MLP | 全Layer学習 | 全Layer学習 |

「Pinpoint（ピンポイント）」の名称に反し、実質的にはほぼfull fine-tuningに近い。
Headは25-30%の選択だが、同一Layer内のMLPも含めると学習パラメータ数は大幅に増加する。

**3. KL制約の欠如**

RL系手法のbeta=0.1によるKLペナルティに相当する正則化がSFTにはなく、
ベースモデルからの無制約な逸脱を許容している。

**4. Catastrophic Forgetting**

igakuqaデータのみでのSFTにより、specialistで-16ptという大幅劣化が発生。
内科のみ壊れ率が低い（~20%）ことは、学習データに含まれる知識領域は比較的保持されるが、
含まれない領域（専門科固有の知識）が優先的に破壊されたことを示唆する。

### 4.2 Positive vs Negative の構造的差異と結果の関係

**PatchPatchingが示した構造的知見:**

| ヘッド種類 | 集中層 | 仮説上の役割 | SFT結果 |
|-----------|--------|------------|---------|
| Positive | 浅い〜中間層 | 汎用的特徴の「干渉」 | 全体的に壊れ率が高い |
| Negative | 深い層 | タスク固有の「推論」 | specialistでやや壊れにくい |

- **Positive（浅い層が主）**: 浅い層の汎用的表現を変更 → 全タスクに波及 → igakuqa/specialist両方で大きく劣化
- **Negative（深い層が主）**: 深い層の推論を変更 → specialistでは若干マシ(48.2% vs 44.9%) → タスク固有推論がより保持された可能性

ただし両方とも大幅劣化しているため、この差異は学習設定の問題に比べれば副次的である。

### 4.3 PatchPatching分析の評価

PatchPatchingによるヘッド分類自体は有意義な構造的発見を提供している:

1. **浅い層 = 干渉、深い層 = 推論**: モデル内部構造の理解に寄与
2. **Negativeヘッドの方がimpactが大きい**: 医療タスクに直接関与するヘッドの特定
3. **Layer9:Head3の突出**: 単一ヘッドが大きなimpactを持つ事例

問題はPatchPatchingの知見ではなく、その知見を活用するSFTの設定にある。

### 4.4 ガイドライン問題

guideline_wrong_filteredの正解率が全モデルで10-16%台にとどまる。
Pinpoint SFTでさらに低下（-4〜-5pt）するが、Baseモデルでも16%程度であり、
ガイドライン改訂内容の正誤判断はLLMの知識カットオフ問題が主因と考えられる。

## 5. Limitations & Future Work

### Limitations

1. **1設定のみの実験**: lr、freeze範囲、ヘッド選択数など最適化は未実施
2. **MLPが学習対象**: `pinpoint_freeze_mlp=false` のため、ヘッド選択の効果が希薄化
3. **SFTのepoch数(1)**: より少ないstep数（early stopping）の効果は未検証
4. **30Bモデルのみ**: 80Bモデル上でのPinpoint SFTは未実施
5. **PatchPatchingのヘッド数閾値**: 全同符号ヘッドを使用しており、上位k個に限定する検証はなし

### Future Work

**改善の優先度順:**

1. **学習率の低減**: lr=1e-4 → 1e-6（RL系と同等）に変更
2. **MLPのfreeze**: `pinpoint_freeze_mlp=true` に変更し、真にヘッドのみの学習を実現
3. **対象ヘッド数の絞り込**: impact上位50〜100ヘッドに限定し、「Pinpoint」を実現
4. **対象Layer数の絞り込**: 全層ではなく、ヘッドが集中する上位10層のみに限定
5. **KL正則化の追加**: SFTにKLペナルティを導入し、Catastrophic Forgettingを抑制
6. **80Bモデル上での実験**: RL系手法との公正な比較を実現
7. **PatchPatching閾値の最適化**: impactスコアの閾値やtop-k選択の検証
